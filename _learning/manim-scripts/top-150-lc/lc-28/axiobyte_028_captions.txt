-- Caption --
Find the First Occurrence — LeetCode 28 (aka strStr) 👇

Return the first index where the needle appears inside the haystack, or -1.

The bread-and-butter approach: slide the needle across the haystack one position at a time. At each start i, compare left to right — needle[k] vs haystack[i+k]. Match the whole needle → that's your index. Hit a mismatch → shift over by one and try again.

haystack "abcabd", needle "abd":
i=0 → a✓ b✓ … c✗d  (so close!)
i=1 → b✗a
i=2 → c✗a
i=3 → a✓ b✓ d✓  → found, index 3 ✅

Bonus (cleaner code): the standard library already does this — haystack.find(needle), and npos means "not found."

→ brute force O(n·m), O(1) space. KMP gets it to O(n+m) by never re-checking characters it already matched.

-- Title --
Find the First Occurrence in a String — LeetCode 28 (Sliding Window / strStr)

-- Description --
Find the Index of the First Occurrence in a String (LeetCode 28), the classic strStr problem.

Return the index of the first time needle appears inside haystack, or -1 if it doesn't. The straightforward approach is a sliding window: try every possible start i from 0 up to n − m, and at each start compare the needle against the haystack character by character. If all m characters match, i is the answer. On the first mismatch, abandon this start, shift the window over by one, and try again.

Worked example: haystack "abcabd", needle "abd". At i = 0 the first two characters match (a, b) but then c ≠ d, so it fails after a partial match. i = 1 and i = 2 mismatch immediately. At i = 3 all three characters match (a, b, d), so the first occurrence is index 3.

⏱️ Brute force is O(n·m) in the worst case with O(1) extra space. The KMP algorithm improves this to O(n + m) by precomputing how far to jump on a mismatch, so it never re-checks characters it already matched.

Bonus, cleaner code (shown as a flourish): the standard library already implements this — size_t p = haystack.find(needle); return p == string::npos ? -1 : (int)p;

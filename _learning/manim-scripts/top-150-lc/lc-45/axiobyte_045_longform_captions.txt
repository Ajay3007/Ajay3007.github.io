-- Title --
Jump Game II: From Recursion to Memoization | LeetCode 45 (Visual DP)

-- Description --
Jump Game II (LeetCode 45), built up from first principles — the intuition, a plain recursion, why it blows up, and how memoization fixes it.

We start with the key idea: standing on a square, the fewest jumps to the end is one jump now, plus the fewest jumps to finish from wherever you land. Because the best finish from a square depends only on the square (optimal substructure), we get a clean recurrence: minJump(i) = 0 at the last index, otherwise 1 + the minimum of minJump(j) over every reachable j.

Then we trace the recursion as a tree for nums = [2,3,1,4], in real call order, watching values return up to the answer of 2 — and we see the problem: the same subproblems, minJump(2) and minJump(3), get recomputed again and again, so plain recursion is exponential.

The fix is memoization: keep a memo array, store each answer the first time, and on any repeat just read it back — which prunes whole subtrees. Each of the n indices is then solved once, giving O(n^2) time (n subproblems x up to n work each) and O(n) space.

A greedy "jump levels" pass then gets this all the way to O(n) time and O(1) space — that's the companion short.

-- Title --
Longest Common Prefix — LeetCode 14 (Vertical Scan + minmax Trick)

-- Description --
Longest Common Prefix (LeetCode 14) solved by scanning down the columns.

Given a list of strings, return the longest prefix common to all of them. The clearest way to see it: stack the words and read straight down the columns. If every string has the same character at column j, that character belongs to the common prefix; the first column where any string differs (or runs out of characters) is exactly where the prefix ends.

Vertical scanning: for each column j, take c = strs[0][j] and compare it against the same column in every other word. As soon as a word has ended (j == s.size()) or shows a different character, return strs[0].substr(0, j). If you get through every column, the whole first string is the prefix.

Example: flower, flow, flight. Column 0 is 'f' for all, column 1 is 'l' for all, but at column 2 flower and flow have 'o' while flight has 'i' — a mismatch — so the answer is "fl".

This runs in O(S) time where S is the total number of characters across the input, using O(1) extra space (no copies until the final substring).

Bonus, cleaner code (shown as a flourish): the common prefix of the entire set is the same as the common prefix of just the lexicographically smallest and largest strings — everything else sits between them. So take minmax_element and compare only those two: int i = 0; while (i < lo->size() && (*lo)[i] == (*hi)[i]) i++; return lo->substr(0, i).

⏱️ O(S) time · O(1) space

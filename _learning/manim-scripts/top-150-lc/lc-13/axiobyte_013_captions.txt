-- Caption --
Roman to Integer — LeetCode 13 — one comparison is all it takes 👇

Roman numerals are almost pure addition: I=1, V=5, X=10, L=50, C=100, D=500, M=1000. The only twist is the six subtractive pairs — IV=4, IX=9, XL=40, XC=90, CD=400, CM=900.

You don't need to memorize those pairs as special cases. There's one rule that generates all of them: a symbol is SUBTRACTED exactly when the symbol right after it is larger. 🧠

So scan left to right:
• if v[i] < v[i+1]  →  total -= v[i]   (it's a discount, like the C in CM)
• otherwise         →  total += v[i]
• the last symbol has no neighbor, so it's always added

MCMXCIV → +1000 (M) −100 (CM) +1000 (M) −10 (XC) +100 (C) −1 (IV) +5 (V) = 1994 ✅

→ O(n) time, O(1) space

-- Title --
Roman to Integer — LeetCode 13 (One-Pass, O(1) Space)

-- Description --
Roman to Integer (LeetCode 13) solved with a single left-to-right pass.

Roman numerals map to values — I=1, V=5, X=10, L=50, C=100, D=500, M=1000 — and are read as a sum, with one exception: six subtractive pairs (IV=4, IX=9, XL=40, XC=90, CD=400, CM=900). The elegant realization is that you don't have to special-case those pairs. They all follow from a single rule: a symbol is subtracted precisely when the symbol immediately to its right is larger than it.

So walk the string once. For each symbol, add its value to the total — unless its right neighbor is larger, in which case subtract it instead. The final symbol has no right neighbor, so it is always added.

Example: MCMXCIV. M(1000) is added; C(100) sits before M(1000) so it is subtracted, giving the CM = 900; M(1000) is added; X(10) before C(100) is subtracted, the XC = 90; C(100) is added; I(1) before V(5) is subtracted, the IV = 4; and V(5), the last symbol, is added. Total: 1000 − 100 + 1000 − 10 + 100 − 1 + 5 = 1994.

⏱️ O(n) time · O(1) space

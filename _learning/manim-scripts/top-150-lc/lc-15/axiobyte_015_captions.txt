3Sum — LeetCode 15 — the two-pointer boss level 👇

Find every UNIQUE triplet that sums to 0. The brute force is O(n³); here's the O(n²) way everyone expects in interviews.

The unlock is SORTING. Once sorted:
• fix one number nums[i]
• the rest is Two Sum — two pointers (l, r) hunting for -nums[i]
• sum < 0 → l++ (need bigger), sum > 0 → r-- (need smaller), sum == 0 → record it
• skip repeated values of i, l and r so you never emit the same triplet twice

nums = [-1,0,1,2,-1,-4] → sorted [-4,-1,-1,0,1,2]:
fix -4 → nothing reaches it
fix -1 → (-1,2) and (0,1) both work → {-1,-1,2}, {-1,0,1}
the second -1 is a repeat → skip (no duplicates)
fix 0 → smallest pair already overshoots → done ✅

→ O(n²) time, O(1) extra space.

-- Title --
3Sum — LeetCode 15 (Sort + Two Pointers, O(n²))

-- Description --
3Sum (LeetCode 15) solved with sorting plus the two-pointer technique — the capstone of the Two Pointers section.

Find all unique triplets that sum to zero. Sorting the array first is the key: it lets you fix one element nums[i] and reduce the rest of the problem to Two Sum on a sorted array. Put l just after i and r at the end; look at s = nums[i] + nums[l] + nums[r]. If s is negative, move l right for a bigger value; if positive, move r left for a smaller one; if zero, record the triplet. To keep triplets unique, skip over repeated values of i (the fixed element) and of l and r after a match.

Example: nums = [-1,0,1,2,-1,-4] sorts to [-4,-1,-1,0,1,2]. Fixing -4, no two later numbers sum to 4. Fixing the first -1, the pointers find (-1, 2) and then (0, 1), giving {-1,-1,2} and {-1,0,1}. The second -1 is a duplicate of the value we just fixed, so we skip it to avoid repeating triplets. Fixing 0, even the smallest available pair overshoots, so we stop. Result: {-1,-1,2} and {-1,0,1}.

⏱️ O(n²) time (an O(n) two-pointer sweep for each of the n fixed elements), plus O(n log n) to sort, and O(1) extra space.

Insert Delete GetRandom in O(1) — LeetCode 380 — a classic design problem 👇

Build a set (RandomizedSet) where insert, remove, AND getRandom are all O(1) average. The clever part is combining TWO structures. 🧠

• getRandom must be uniform → keep the elements in an ARRAY, pick a random index → O(1)
• insert/remove must find a value fast → a HASH MAP from value → its index in the array

Insert is easy (append + record the index). getRandom is easy (v[random index]).

Remove is the trick. Deleting from the middle of an array is O(n) because of shifting. So instead: look up the value's index, SWAP it with the LAST element, update the last element's index in the map, then pop_back. Order doesn't matter in a set, so this is a totally valid O(1) delete. ✅

array + hash map + swap-with-last = all O(1)

-- Title --
Insert Delete GetRandom O(1) — LeetCode 380 (Array + HashMap)

-- Description --
Insert Delete GetRandom O(1) (LeetCode 380) — designing RandomizedSet so that insert, remove, and getRandom are all O(1) average.

The whole problem is about combining two data structures so each one covers the other's weakness. getRandom has to return a uniformly random element, which means the elements need to live in an array so you can pick a random index in O(1). But an array alone can't find a value quickly, so we add a hash map from each value to its index in the array, giving O(1) lookups for insert and remove.

Insert appends to the array and records the new index in the map. getRandom just returns the element at a random index.

Remove is the interesting one. Deleting from the middle of an array is O(n) because everything after the gap has to shift. The trick: look up the value's index, swap it with the LAST element of the array, update that moved element's index in the map, and then pop_back. Since a set has no order, moving the last element into the gap is perfectly fine — and it makes deletion O(1).

Example: v = [1,2,3], map = {1:0, 2:1, 3:2}. remove(2): 2 is at index 1, swap in the last element 3 -> v = [1,3], set map[3] = 1, pop the last slot, erase 2 -> map = {1:0, 3:1}.

⏱️ O(1) average for insert, remove, and getRandom · O(n) space

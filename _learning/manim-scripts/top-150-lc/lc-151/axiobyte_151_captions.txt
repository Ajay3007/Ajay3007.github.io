Reverse Words in a String — LeetCode 151 — three clean steps 👇

Reverse the ORDER of the words (not the letters), and trim the mess: leading, trailing, and repeated spaces all collapse to one.

Think of it as tiles 🧱
1) tokenize → pull out the words. In C++, stringstream's >> skips EVERY run of whitespace automatically, so all the extra spaces vanish for free.
2) reverse → flip the list (the end words swap inward).
3) join → glue them back with a single space.

"  the sky is  blue "  →  [the][sky][is][blue]  →  [blue][is][sky][the]  →  "blue is sky the" ✅

Bonus (cleaner code): read each word and PREPEND it to the result — res = word + " " + res. The order flips itself, no vector and no reverse call.

→ O(n) time, O(n) space (O(1) if you reverse in place: flip the whole string, then flip each word back)

-- Title --
Reverse Words in a String — LeetCode 151 (Tokenize, Reverse, Join)

-- Description --
Reverse Words in a String (LeetCode 151), broken into three clean steps.

Given a string, reverse the order of its words and normalize the spacing: strip leading and trailing spaces and collapse any run of spaces between words down to one.

The three steps: (1) tokenize — extract the words; (2) reverse — flip the list of words; (3) join — concatenate them with a single space. In C++ the tokenizing step is especially clean because reading from a stringstream with the >> operator automatically skips every stretch of whitespace, so the leading, trailing, and doubled spaces are handled for free — you never write special-case code for them.

Example: "  the sky is  blue " tokenizes to [the, sky, is, blue], reverses to [blue, is, sky, the], and joins to "blue is sky the".

Bonus, cleaner code (shown as a flourish): instead of storing a vector and calling reverse, read each word and prepend it to the running result — res = word + (res.empty() ? "" : " ") + res. Reading left to right while prepending produces the reversed order directly, with no container and no reverse call.

⏱️ O(n) time · O(n) space. You can reach O(1) extra space with the in-place double reverse: reverse the entire string, then reverse each individual word back (compacting the spaces in the same pass).

Remove Duplicates from Sorted Array — LeetCode 26 — in O(1) space 👇

The key nobody says out loud: the array is SORTED. 🧠 That means every duplicate sits right next to its twin — so you never search, you just compare each value to the last unique one you kept.

Two pointers on one array:
• s → the last unique value
• f → scans ahead

If nums[f] equals nums[s], it's a duplicate → skip it. If it's different, it's a new unique → move s forward and copy it there.

At the end, the first s + 1 slots hold every unique value, in order. One pass, no extra memory.

→ O(n) time, O(1) space ✅

Remove Duplicates from Sorted Array (LeetCode 26) solved in O(1) space with two pointers — and the whole trick is that the array is sorted.

Because the array is sorted, duplicates are always adjacent, so you only ever compare each element to the last unique value you kept. Keep a slow pointer s on the last unique and a fast pointer f scanning ahead: if nums[f] matches nums[s] it's a duplicate and you skip it; if it differs, it's a new unique, so you advance s and copy it there. When you're done, the first s + 1 elements are all the unique values in order — one pass, no extra memory.

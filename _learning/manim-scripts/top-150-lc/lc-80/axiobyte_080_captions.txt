Remove Duplicates from Sorted Array II — LeetCode 80 — each value at most twice, O(1) space 👇

Part I let each value appear once. Now it's twice. The elegant trick: because the array is SORTED, just look TWO slots back. 🧠

Keep a write pointer s and scan with f. To decide if nums[f] earns a spot, compare it to nums[s−2] — the value two positions back in your result:
• if they're equal → slots s−1 and s−2 already hold two copies, so this would be a 3rd → skip
• if they differ → keep it (advance s, copy it)

The s < 2 check just waves the first two elements through. That's it — at most two of everything, one pass, no extra memory.

→ O(n) time, O(1) space ✅

Remove Duplicates from Sorted Array II (LeetCode 80) — keep each value at most twice, in O(1) space. The follow-up to LeetCode 26, and the trick is to look two slots back.

Keep a write pointer s and scan the array with a fast pointer f. Because the array is sorted, you can decide whether to keep nums[f] by comparing it to nums[s-2] — the value two positions back in the result. If they're equal, slots s-1 and s-2 already hold two copies of that value, so keeping this one would make a third → skip it. If they differ, keep it: write it at s and advance. The s < 2 guard lets the first two elements through automatically. When the loop ends, the first s elements hold the answer — one pass, no extra memory.

⏱️ O(n) time · O(1) space

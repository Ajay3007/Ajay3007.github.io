Length of Last Word — LeetCode 58 — scan the RIGHT end 👇

The instinct is to split the string on spaces and grab the last piece. But that allocates a whole array of words just to read one number. There's a cleaner move.

The last word lives at the END of the string — so walk backwards. 🔁
1) skip any trailing spaces (i--)
2) then count letters until you hit a space (len++, i--)
3) that count IS the answer

s = "a moon  " → skip the 2 trailing spaces, then count n, o, o, m → len = 4 ✅

You never touch anything but the last word: O(n) time, O(1) space, no extra arrays.

Pro one-liner (C++): end = s.find_last_not_of(' '); return end - s.find_last_of(' ', end); — the STL walks back for you.

-- Title --
Length of Last Word — LeetCode 58 (Reverse Scan, O(1) Space)

-- Description --
Length of Last Word (LeetCode 58) solved with a single backward scan.

Given a string of words separated by spaces, return the length of the last word. The tempting approach is to split on spaces and take the last token, but that allocates an array of words just to compute one integer. Since the last word is at the end of the string, it's cleaner to scan from the right.

Start an index i at the last character with a counter len = 0. First, while s[i] is a space, decrement i — this skips any trailing spaces. Then, while i is still in range and s[i] is not a space, increment len and decrement i — this counts the characters of the last word until you reach the space in front of it (or the start of the string). Return len.

Example: s = "a moon  ". The two trailing spaces are skipped, then n, o, o, m are counted for a length of 4.

This touches only the last word, so it's O(n) time in the worst case and O(1) extra space — no splitting, no extra arrays.

Elegant alternative (shown as a flourish): int end = s.find_last_not_of(' '); return end - s.find_last_of(' ', end); — the STL scans backward for you. This leans on find_last_of returning npos when the word begins at index 0, where the unsigned subtraction end - npos evaluates to end + 1, exactly the length. It's safe here because the problem guarantees at least one word.

⏱️ O(n) time · O(1) space

# 🚀 The Decap CMS Editorials Workflow

Writing dedicated solution approaches and code snippets for a problem is now entirely streamlined directly within your browser.

## Step 1: Write the Editorial
1. Log into your CMS Dashboard: [ajay3007.github.io/admin](https://ajay3007.github.io/admin)
2. On the left sidebar, click **DSA Editorials**.
3. Click **New DSA Editorial**.
4. Fill in the **Title** (e.g. "Valid Palindrome Solution"). Provide the **Problem ID**, select today's **Publish Date**, and write your beautiful Markdown approach + code blocks in the **Body**.
5. Click **Publish**!

## Step 2: Link the Problem
1. When you hit publish, Jekyll will instantly generate a dedicated web page at `/editorials/your-kebab-slug/` (e.g., `/editorials/valid-palindrome-solution/`).
2. Inside your CMS Admin panel, navigate to **Data Files** --> **DSA Problems Database**.
3. Find your specific problem, and paste `/editorials/your-kebab-slug/` directly into the *My Solution Link* or *My Approach Link* widget fields.
4. Click **Publish**.

*Your glorious dedicated problem notebook is now live on the Problems Hub table!*

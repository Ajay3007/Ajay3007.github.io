# 🏗️ High-Level Design (HLD)

Architecture and system-level design projects.

---

## Projects

Start a new HLD project by creating a folder with the following structure:

```
hld/
└── <project-name>/
    ├── requirements.md
    ├── architecture.md
    ├── tradeoffs.md
    ├── diagrams.md
    └── README.md
```

### Project Template

When you create a new HLD project, include:

- **requirements.md** — Functional and non-functional requirements
- **architecture.md** — High-level system design and components
- **tradeoffs.md** — Design decisions and trade-offs
- **diagrams.md** — System architecture diagrams (Mermaid format)
- **README.md** — Project overview and navigation
